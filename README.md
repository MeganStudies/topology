# Introduction to Topology

This course is an Introduction to the branch of geometry that is topology. While the materials that I will be using to learn the subject are entirely from outside sources, this syllabus was crafted by me, Megan Coyne, for the University of Megan. If you have somehow found this site and would like to follow along, please beware, I am decently (at the undergraduate level) familiar with analysis and this course is assuming that the student taking it is knowledgeable in this area as well. I will be using materials to supplement anything I may not recall from analysis, but I will not be spending dedicated time in this course reviewing any analysis.

## Textbook

* To learn this subject, I will primarily be using [Topology without Tears by Sydney Morris](https://www.topologywithouttears.net/topbook.pdf)
* For any analysis review I may need, I will be using the sources we used in my Real Analysis course at UD
    * [Understanding Analysis by Stephen Abbott](https://www.amazon.com/Understanding-Analysis-Undergraduate-Texts-Mathematics/dp/1493927116)
    * [Basic Analysis I & II by Jiri Lebl](https://www.jirka.org/ra/html/ra-3.html)

## Assignments

There will be a problem set to complete each week. Some weeks and days there may be a small paper, or a discussion post, or something of that sort as well. Problem sets and any writing assignments will be uploaded to GitHub to signal completion. Discussion posts will need to be written in the directed location and a link to the comment made must be provided. There will also be a course-long project. There will be one checkpoint in the middle of the course to ensure appropriate progress is being made. It must be clear that the project is at least halfway finished, adequately drafted, or a mixture of both at this checkpoint.

## Quizzes and Exams

* 1 Final Exam - allotted 2 hours to complete
* 4 Quizzes - allotted 1 hour to complete each
